# 해석학 탐구 주제 찾기

수학 수행평가 주제를 고르기 어려운 학생을 위한 도구입니다. 지금 알고 있는 개념을 입력하면, 개념 사이의 선행 관계를 그래프로 계산해 해석학 탐구 주제를 추천하고 학습 순서와 난도를 함께 보여줍니다.

## 왜 만들었나

수학 주제는 이름만 봐서는 난도도, 무엇을 먼저 알아야 하는지도 알기 어렵습니다. 그래서 주제를 고르고도 시작하지 못하거나, 너무 어려운 주제를 고르는 일이 생깁니다. 이 도구는 "내가 아는 것에서 이 주제까지 몇 걸음인가"를 계산해 그 판단을 돕습니다.

## 어떻게 작동하나

- 고등학교 교과 개념 13개와 해석학 개념 28개를 정점으로, 선행 관계를 방향 간선으로 둔 그래프(DAG)를 만들었습니다.
- 목표 개념에서 역방향으로 조상을 탐색하다가 아는 개념을 만나면 멈춥니다. 남은 것이 새로 배워야 할 선행개념입니다.
- 그 부분그래프를 위상 정렬해 학습 순서와 단계 수를 계산합니다.
- 난도는 선행개념의 수(0.50), 학습 경로의 깊이(0.25), 개념의 추상성(0.25)을 합쳐 5단계로 표시합니다.

아는 정도는 모름 / 들어봤음 / 잘 앎 세 단계로 입력합니다. "들어봤음"인 개념은 목록에서 사라지지 않고 복습 항목으로 남으며, 난도 계산에서 절반의 무게로 셉니다.

## 기능

- 조건(아는 개념, 관심 방향, 난도, 결과물 형태)에 맞는 탐구 주제 추천
- 선행개념 분석과 학습 순서 제시
- 난도 계산과 그 근거(개념 수, 깊이, 추상도) 표시
- 개념 지도 — 아는 개념에서 주제까지의 경로를 그림으로 표시
- 탐구 계획 내보내기 — 수행평가 계획서에 붙일 수 있는 형태로 정리
- 인쇄

## 검증

세 가지 기능을 각각 테스트했습니다.

| 항목 | 확인한 것 | 결과 |
| --- | --- | --- |
| 선행개념 분석 | 학습 순서가 선행 관계를 어기지 않는가 | 21개 주제 전체에서 순서 위반 0건 |
| 난이도 계산 | 아는 개념이 늘 때 난도가 올라가지 않는가 | 위반 0건 |
| 난이도 계산 | 직접 매긴 난이도 순위와 일치하는가 | 순서쌍 10개 중 10개 일치 |
| 주제 추천 | 입력한 조건이 결과에 반영되는가 | 조건 불일치 0건 |

## 한계

- 개념의 난도는 사람마다 다르게 느껴져 완전히 객관적으로 정할 수 없습니다.
- 교재에 따라 개념의 설명 순서와 선행 관계가 조금씩 다릅니다.
- 아는 정도를 세 단계로 나누는 것 역시 학생 자신의 주관적 판단입니다.
- 복습 개념을 절반으로 세는 기준은 검증되지 않은 임의값입니다.

이 도구의 결과는 참고 자료입니다. 최종 주제는 교사의 검토를 함께 받는 것이 좋습니다.
